# The Fair Game

A computational wealth distribution simulation exploring inequality, poverty, and redistribution under different economic systems.

## Features
- Free Market simulation

- Welfare Society simulation
- Egalitarian Utopia simulation
- Gini coefficient analysis
- Lorenz curve visualization
- Comparative economic analysis

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## Live App
https://thefairgame.streamlit.app/


## Run Locally
pip install -r requirements.txt
streamlit run app.py
